# 🌾 AgriConnect

## Overview
AgriConnect is a full-stack MERN web application designed to connect Farmers, Workers, and Contractors on a single platform. It streamlines agricultural workforce management by enabling secure job posting, job searching, user profiles, and real-time communication.

## Features

### Authentication
- User Registration
- Login
- JWT Authentication
- Password Reset
- Role-Based Access

### User Profiles
- Farmer Profile
- Worker Profile
- Contractor Profile
- Aadhaar Verification
- Skills & Experience
- Farm Information
- Profile Photo Upload

### Job Management
- Create Job
- Edit Job
- Delete Job
- Search Jobs
- Filter Jobs
- Save Jobs
- Apply for Jobs

### Messaging
- Real-time Chat
- Notifications

### Admin Panel
- User Management
- Job Moderation
- Verification Requests
- Analytics Dashboard

# System A: AgriConnect Platform Trust Engine & Dynamic Badges

> [!IMPORTANT]
> **DISCLAIMER**: System A Trust Score is a platform reputation and reliability metric calculated from user activity, profile completeness, completed work history, and skill certificates. **It is NOT a government identity verification service.**

---

## Trust Score Calculation (0 – 100 Score)

The Trust Score evaluates platform signals using dynamic, configurable weights stored in `PlatformSetting`:

| Signal Component | Default Points | Description |
| :--- | :--- | :--- |
| **Mobile Verification** | `15 Points` | Verified OTP phone number |
| **Email Verification** | `10 Points` | Verified email address |
| **Profile Completeness** | `15 Points` | Name, location, bio, photo uploaded |
| **Skill Certificates** | `20 Points` | Approved agricultural skill certificates (5 pts / cert) |
| **Completed Work History** | `20 Points` | Successfully completed farm jobs (2 pts / job) |
| **User Ratings** | `20 Points` | Average farmer ratings (proportional to 5.0) |

---

## Dynamic Trust Levels

- `0 – 29`: **`BASIC`** (New platform registrant)
- `30 – 49`: **`VERIFIED`** (Basic phone + profile verified)
- `50 – 69`: **`SKILLED`** (Certificates uploaded / verified skills)
- `70 – 84`: **`TRUSTED`** (Consistent completed jobs & positive ratings)
- `85 – 100`: **`TOP_RATED`** (High score + 4.5+ average rating)

---

## System A Badges

- `MOBILE_VERIFIED`: Issued upon mobile OTP validation.
- `EMAIL_VERIFIED`: Issued upon email link verification.
- `PROFILE_COMPLETE`: Issued upon filling required profile details.
- `SKILL_VERIFIED`: Issued upon admin approval of an agricultural skill certificate.
- `EXPERIENCED_WORKER`: Issued after completing 5+ farm jobs.
- `TRUSTED_WORKER`: Issued when Trust Score reaches 70+.
- `TOP_RATED_WORKER`: Issued when Trust Score reaches 85+ with 4.5+ average rating.

*(Note: `IDENTITY_VERIFIED` is issued exclusively by System B Aadhaar e-KYC and is never generated by Trust Score logic).*
